# 📊 Sales Analytics Dashboard - Operational Guide

Welcome to the Sales Analytics Dashboard. This document provides comprehensive instructions for installing, configuring, and operating the dashboard with various data backends, including **Google Sheets**.

---

## 🚀 1. Installation

### Local Setup
1.  **Clone the Repository**:
    ```bash
    git clone <your-repo-url>
    cd dashboard
    ```
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Environment Configuration**:
    Copy the example environment file:
    ```bash
    cp .env.example .env.local
    ```
    Open `.env.local` and configure your preferred `DATA_SOURCE` (csv, supabase, or google_sheets).
    *   To use CSV: `DATA_SOURCE=csv`
    *   To use Supabase: `DATA_SOURCE=supabase` (Requires credentials below)

4.  **Run Development Server**:
    ```bash
    npm run dev
    ```
    Access the app at `http://localhost:3000`.

## 📈 2. Google Sheets & Apps Script Integration

You can power this dashboard directly from a Google Sheet. Follow these steps to set up the connection:

### Step A: Prepare the Google Sheet
1. Create a new Google Sheet.
2. In the first row, add the following headers (case-sensitive):
   `date`, `order_id`, `product`, `channel`, `revenue`, `profit`
3. Add your data in the rows below.

### Step B: Set Up Google Apps Script
1. In your Google Sheet, go to **Extensions** > **Apps Script**.
2. Replace the existing code with the following script:

```javascript
/**
 * Serves the Google Sheet data as JSON for the Sales Dashboard
 */
function doGet() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheets()[0]; // Access the first sheet
  const data = sheet.getDataRange().getValues();
  const headers = data[0];
  const rows = data.slice(1);

  const result = rows.map(row => {
    let obj = {};
    headers.forEach((header, i) => {
      obj[header] = row[i];
    });
    return obj;
  });

  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}
```

### Step C: Deploy the Script
1. Click **Deploy** > **New Deployment**.
2. Select **Type**: "Web App".
3. **Description**: "Dashboard API".
4. **Execute as**: "Me".
5. **Who has access**: "Anyone". (This is necessary for the dashboard to fetch the data).
6. Click **Deploy** and copy the **Web App URL**.

### Step D: Link to Dashboard
Update your `.env.local`:
```env
DATA_SOURCE=google_sheets
GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
```

## 📅 3. Connecting to Supabase (Real Database)

The backend API is configured to read data from a local CSV by default, but is fully ready to connect to Supabase. This allows you to scale beyond simple files.

### Step-by-Step Guide
1.  **Create a Project**: Go to [Supabase](https://supabase.com/) and create a new project.
2.  **Initialize Database**: In the **SQL Editor**, create the `sales_data` table by running this snippet:
    ```sql
    CREATE TABLE sales_data (
       id bigint generated by default as identity primary key,
       date date,
       product text,
       channel text,
       orders numeric,
       revenue numeric,
       cost numeric,
       visitors numeric,
       customers numeric
    );
    ```
3.  **Import Data**: Import your CSV data into this table via the **Supabase Table Editor** (Upload CSV button).
4.  **Get Credentials**: Go to **Project Settings** -> **API** to get your **URL** and **Anon Key**.
5.  **Update Config**: In your local `.env.local` file, add your credentials and set the `DATA_SOURCE`:
    ```env
    DATA_SOURCE=supabase
    NEXT_PUBLIC_SUPABASE_URL=your_project_url
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
    ```
6.  **Restart Server**: Restart your development server. The API will now serve data directly from Supabase!
